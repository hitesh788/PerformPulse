1. Executive Summary

PerformPulse is a comprehensive, enterprise-grade Performance Management System built on the MERN stack with real-time WebSocket communication. It digitises and automates the complete employee performance lifecycle — from KPI assignment and progress tracking, to managerial 9-box talent mapping, 360-degree peer assessments, AI-generated review drafts, and executive analytics dashboards. The platform enforces strict Role-Based Access Control (RBAC) across three tiers: Admin, Manager, and Employee, each with a dedicated, purpose-built interface.

3. System Architecture

PerformPulse uses a Monolithic MERN Architecture with a clear separation between frontend and backend concerns. A single Node.js server handles both the REST API (Express) and the WebSocket layer (Socket.io), minimizing infrastructure complexity. The React frontend communicates with the backend entirely through a centralized Axios instance that handles authentication automatically.

[Browser] React SPA (Vite Dev Server → Port 5173)
    ↕ HTTP/REST (Axios + JWT Header)
    ↕ WebSocket (Socket.io — Persistent Connection)
[Server] Node.js + Express (Port 5000)
    ├── /api/auth    → User Registration, Login, JWT Issuance
    ├── /api/kpi     → KPI CRUD, Progress Updates
    ├── /api/evaluation → Scores, Feedback, Analytics
    ├── /api/notification → Push + Broadcast System
    ├── /api/admin   → Cycles, Activity Logs
    └── Socket Events → newNotification, join, broadcast
[Database] MongoDB Atlas / Local (Mongoose ODM)

6. Core Feature Deep-Dive
  • 🔐

    JWT Authentication & Secure Registration

    Stateless authentication using signed JWTs. Passwords are hashed with bcrypt before storage. A Forgot Password flow issues temporary credentials that force a mandatory password reset on next login.

  • 📊

    KPI Management (Full CRUD)

    Employees create strategic KPIs categorized under Innovation, Customer Success, Operational Excellence, or Team Leadership. Progress is tracked via a numerical counter with a real-time gradient progress bar. Managers can audit and assign a score (1–5) per KPI, which feeds the leaderboard.

  • ⚡

    Real-Time Notification System (Socket.io)

    A persistent WebSocket connection is established on login. Managers and Admins can broadcast priority announcements that are instantly pushed to all connected employee sessions. Notifications persist in the database and display an unread count badge on the navbar bell icon.

  • 🤖

    AI-Augmented Review Generation

    Managers can trigger an AI synthesis engine that analyses the employee's KPI completion ratio and generates a data-driven, corporate-grade performance review draft — covering executive summary, observed strengths, and strategic development vectors. The draft is editable before final submission.

  • 🗺️

    9-Box Talent Mapping Matrix

    An interactive 3×3 grid that maps employees along Performance (X-axis) and Potential (Y-axis) axes into nine archetypes: Future Leader, High Impact, Core Employee, Enigma, Underperformer, etc. Managers click a cell to classify the employee, which is stored with the evaluation record.

  • 🏆

    Organization-Wide Elite Leaderboard

    A MongoDB aggregation pipeline computes each employee's average manager-submitted score. Results are ranked and displayed with rank medals, department badges, and score metrics. The leaderboard is accessible from every employee dashboard to foster healthy competition.

  • 🔁

    360-Degree Peer Assessment

    Employees can submit structured qualitative assessments and star ratings (1–5) for any peer in the organization. Received assessments are visible on the peer's Managerial Synthesis card, contributing to a holistic view of their performance reputation.

  • 📈

    Enterprise Analytics Dashboard

    Available to Admins and Managers. Displays four real-time computed charts: Monthly Performance Trend (Line Chart), Category-wise Comparison (Horizontal Bar), Top Performers Ranking, and Talent Distribution Donut Chart. All data comes from live MongoDB aggregation — no mock data.

  • 🗂️

    Admin Command Center

    A tabbed management console with three modules: (1) Identity Governance — full user CRUD with universal search; (2) Appraisal Orchestration — create and toggle review cycle statuses; (3) Critical System Audit — an immutable, monospace terminal-style log of all high-privilege operations with ISO timestamps.

  • 📄

    Print-to-PDF Performance Export

    Employees can export their complete performance dashboard — KPI table, feedback cards, and ratings — as a clean, printer-friendly PDF using the browser's native print engine with special @media print styles that hide navigation and interactive elements.

8. Security Implementation
  • 🔒

    JWT-Based Stateless Auth

    All sensitive endpoints are protected by a middleware that validates the Bearer token in the Authorization header. Invalid or expired tokens return a 401 Unauthorized response.

  • 🛡️

    Role-Based Middleware

    Dedicated middleware functions (requireAdmin, requireManager) are applied to API routes to prevent privilege escalation. A Manager cannot access Admin routes and vice versa.

  • 🔑

    bcrypt Password Hashing

    Raw passwords are never stored. bcryptjs applies a one-way adaptive hash with configurable salt rounds before persisting to MongoDB, ensuring credentials are secure even in the event of a database breach.

  • 📋

    Immutable Audit Trail

    All high-privilege administrative operations (user creation, suspension, cycle changes) are recorded in an ActivityLog collection with the actor's name, action type, details, and ISO timestamp — creating a compliance-ready audit record.

  • 🔄

    Forced Password Reset

    When an Admin provisions a new account or resets credentials via the Forgot Password flow, the isTemporaryPassword flag is set to true. The frontend intercepts the login response and forces the user to change their password before accessing any feature.

slideUp and fadeIn keyframe animations on mount. Hover: translateY(-2px) lifts and box-shadow glow transitions for all interactive elements.

Responsive

Mobile-First Grid

CSS Grid auto-fit/minmax patterns collapse from multi-column to single-column below 768px. Horizontal table scroll for data-dense views.

Identity System

Role-Coloured Avatars

Navbar identity badge dynamically colors the avatar: Amber for Admin (Root Authority), Emerald for Manager (Leadership Node), Indigo for Employee (Operational Staff).
